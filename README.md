# LIMA-EFDJSP
Benchmark instances and experimental results for the LIMA algorithm.
This repository contains the benchmark instances and raw Pareto fronts for the paper “Learning-Driven Island Memetic Algorithm for Energy-Efficient Fuzzy Distributed Job-Shop Scheduling.”
The archive Raw data.zip contains three folders:

Benchmark instances: The instances used in the experiments.
ablation study: Raw Pareto fronts from 20 independent runs of each algorithm on each instance in the ablation experiments.
comparison with other algorithms: Raw Pareto fronts from 20 independent runs of each algorithm on each instance in the comparative experiments.

Download and extract Raw data.zip to access the files.
